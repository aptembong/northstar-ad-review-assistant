# Portfolio backup copies

Offline copies of every page in the [Northstar Harbor case study](https://claude.ai/artifact/3eRUWtX9zD8umwhvwBLeP2), in case the live links are ever unavailable. Each folder has the page as **HTML** (clickable, with its tabs and walkthroughs) and a **PDF** of its main view.

## How to open them

GitHub shows HTML files as code, so download them first:

1. Go to the [repository's main page](https://github.com/aptembong/northstar-ad-review-assistant).
2. Click the green **Code** button, then **Download ZIP**.
3. Unzip the file and open `portfolio-static/index.html` in any web browser.

To read a single PDF, click it in GitHub. It opens right in the browser.

## Notes on the offline copies

- Links between pages open the other backup copies, so the whole set works offline.
- **Ad Review Assistant:** live reviews need a Claude sign-in and only work on the live page. Offline, use **Watch a demo run** and the sample ads.
- **Explainer video:** the video file isn't included. Watch it on the live case study.
- Fonts load from Google Fonts when you're online; offline, your browser uses similar fonts.

Northstar Harbor Mortgage is a fictional company created for portfolio purposes. All names and figures are illustrative.
